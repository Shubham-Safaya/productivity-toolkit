# Sundays with Safaya

Personal brand hub and email capture for a product management practitioner. One practical PM career note, most Sundays.

Pure static site: `index.html`, `styles.css`, `app.js`. No build step, no frameworks, no imagery — the typography is the design.

- **Live**: https://shubham-safaya.github.io/sundays-with-safaya/
